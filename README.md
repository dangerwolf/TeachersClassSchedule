## 原始需求
我是一名老师，每天要给不同班的学生上不同的课程。我需要一款在线课表系统。可以自己添加课程名称，上课教室，以及上课时间，并能通过颜色标记不同班级以便我快速区分。然后可以导出数据，以及在线打印。同时提供移动端查看支持，确保我可以随时随地掌握课表变化。
## 核心功能与设计亮点
* 多班级专属色彩标记
  * 班级色彩系统：为不同班级（如高一(1)班、高一(3)班、高二选修班等）分配高对比度、清晰柔和的主题色，课表卡片与标签自动根据班级换色，一目了然。
  * 一键班级聚焦高亮：顶部提供班级筛选胶囊栏，点击特定班级即可在整张周课表中高亮 spotlight 该班的所有课程。
  * 班级与色彩管理：支持随时增删班级、修改学生人数、默认固定教室及自定义配色。
* 灵活排课与防冲突提醒
  * 全要素排课：支持设定课程名称、授课班级、上课教室/实验室、星期节次、单双周交替（每周/单周/双周）及备课要点/作业提醒。
  * 网格一键加课：点击周课表矩阵中任意空白时间段的「+」即可自动带入该时段快速加课。
  * 智能冲突预警：当同一时间段排入多门课程时，自动显示冲突警示条，同时兼顾合班授课与单双周灵活排课。
* 多维度视图与移动端随时查看
  * 周课表矩阵视图：标准周课表布局，清晰划分早读、上午、下午、晚自习与大课间，支持 5天工作日制 与 7天完整周 一键切换。
  * 今日聚焦与下节课倒计时（手机端极佳体验）：包含实时时钟、精准的「下一节课预告」或「正在上课」状态卡片，标注教室位置与备课笔记，方便教师课间快速转场。
  * 课程清单与快速检索：支持按关键词（课程名、教室、班级、笔记）、按星期、按班级多重检索与批量维护。
  * 教学负荷与统计分析：自动统计周课时总数、教学进度达成率、各班课时占比条形图及工作日授课节奏对比。
* 在线打印与排版引擎
  * 标准 A4 打印优化：提供专业的在线打印预览，支持 A4 横版 与 A4 纵版 切换。
  * 正规教学表头与签章栏：打印版包含学校名称、学期、任课教师姓名、班级图例及教研组长审核、教务处盖章区域，点击即可直接调用浏览器打印机输出或保存为 PDF。
* 多格式数据导出与跨端同步
  * 导出 Excel / CSV 表格：方便导入 WPS / Excel 存档或直接向教务处报送。
  * 导出手机日历 (.ics)：可一键导入 iPhone、iPad、Mac 日历、Google 日历及华为/小米等手机系统日历，并在课前 10 分钟自动弹出上课提醒。
  * JSON 完整数据备份与还原：支持将所有课表、自定义作息与班级颜色备份到本地或在其他设备上导入恢复。
